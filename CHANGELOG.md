## 0.2.0 (2026-11-24)

### Feat

- **federation**: filter the neighbours by their relation
- **strategies**: weigh by a softmax of the angles with heurfedamp
- **strategies**: default the pull of pfedgraph to its reference value
- **strategies**: optimise with nesterov momentum, adagrad and fedexp
- **strategies**: aggregate with meamed, geometric medians, centered clipping, sign votes and masks
- **strategies**: weigh by selection probabilities, mixing rows, min norm, angles, histories and similarity
- **strategies**: screen with bulyan, mda, dnc, norms, cosine bipartitions and neighbourhoods
- **strategies**: select in proportion to sizes, in clusters or in turn
- **strategies**: read the number of samples under a configurable key
- **strategies**: include the sampling strategies
- **strategies**: include the update strategies
- **strategies**: include the aggregation strategies
- **federation**: label the parents and children of stars and trees
- **federation**: accept bare versions in the version arithmetic of a model
- **federation**: emulate the computation on the device of an entity
- **federation**: ask the process for the connections of an entity
- **federation**: give entities a numpy generator
- **federation**: find the base and the lag of a version
- **federation**: limit the history of the model per version level
- **federation**: load a received version partially
- **federation**: label the parameters and unflatten any vector
- **federation**: stamp messages with their send, arrival and size
- **federation**: receive from a given sender
- **system**: limit the concurrency of the devices

### Fix

- **strategies**: give no weight to a round made only of sybils
- Require compatible Eclypse version
- **process**: seed the entities once per process
- **system**: pass the other node arguments on to the build of the base node
- Remove intersphinx and add direct external link to ECLYPSE documentation

### Refactor

- **strategies**: give each decision of a round its own module

- **federation**: count the traffic of entities

- **system**: add the exclusive placement strategy
- **data**: add the splitters of the entity data views
