# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
Entries are generated by [commitizen](https://commitizen-tools.github.io/commitizen/)
on each release (`make bump`).

## 0.1.0 (2026-11-05)

### Feat

- **federation**: push entity reports to the simulator
- **process**: default to the mirror system
- evaluate the entities periodically
- **report**: warn about undeclared evaluation metrics
- **federation**: return the recorded version from model writes
- **federation**: let entities reassign their data
- **report**: add the evaluate event and its metrics
- **federation**: let entities evaluate themselves
- share the seed of the process across the federation
- **report**: add the federation metrics
- **federation**: count the traffic of entities
- **federation**: add the star, tree and ring topology builders
- **system**: add the exclusive placement strategy
- **data**: add the splitters of the entity data views
- **data**: add the quantity skew dataset
- **federation**: allow control messages without a model
- **federation**: add a timeout to the receive of entities
- **system**: default the infrastructures to maximal resources
- **federation**: let entities hold no data
- **system**: add the system configuration of the federated process
- **federation**: add model exchange between entities
- **federation**: include the federated model with versioned numpy parameters
- **process**: add the federated process
- **system**: add the device, infrastructure builders and placement strategies
- **federation**: add the entity and the federation application
- **data**: add federated datasets and per-entity views

### Fix

- lint the tests in pre-commit as in ci
- keep uv.lock in sync on version bumps
- **federation**: look up versions on a copy of the history
- **federation**: type the parameters by their requested form
- **federation**: reject duplicate entity identifiers
- **data**: return a view when slicing a data view
- **report**: keep failing evaluations from stopping the process

### Refactor

- **process**: expose the federation and data as plain attributes
